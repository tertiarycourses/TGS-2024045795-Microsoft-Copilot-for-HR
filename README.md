# Agentic AI for HR

![Agentic AI for HR courseware cover](screenshot.png)

WSQ courseware for **TGS-2024045795 — Agentic AI for HR**.

Current trainer deck: **v6.2**. Its administration sequence follows the approved SPC courseware pattern, with separate digital-attendance and trainer-profile pages.

This two-day course uses Microsoft 365 Copilot for generative-AI work and Agent Builder for Microsoft 365 Copilot or Microsoft Copilot Studio for governed agentic-AI workflows.

The learning journey starts with the administrative burden in current HR work, then applies AI to reduce repetitive administration, improve productivity and efficiency, and return HR capacity to strategic people and business value.

## Learner resources

- `courseware/` — trainer slides, Learner Guide (DOCX/PDF plus Markdown mirror) and Lesson Plan
- `activities/` — 12 connected, self-contained HR lifecycle cases with detailed Markdown/PDF instructions, scenario-specific mock data, evidence workbooks and agent tests where relevant
- `SOURCE-COVERAGE.md` — source and coverage traceability
- `QA-REPORT.md` — build and alignment evidence

## HR lifecycle coverage

Talent-needs assessment, inclusive job design, resume screening, structured interviewing, onboarding, talent development, policy, leave, benefits, workforce wellness, offboarding and HR-agent portfolio operations.

## Data safety

All learner cases, names, resumes and operational records are fictional. Do not upload live employee, candidate or company-confidential data to a learning environment.
